# Hello Java Program

This README demonstrates a simple hello world Java program.

## What is This?

This is a basic Java "Hello World" program that showcases the fundamentals of Java programming.

## Hello World Program

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

## How to Compile and Run

### Prerequisites
- Java Development Kit (JDK) installed on your system

### Steps

1. **Save the code** to a file named `HelloWorld.java`

2. **Compile the program:**
```bash
javac HelloWorld.java
```
This creates a `HelloWorld.class` file.

3. **Run the program:**
```bash
java HelloWorld
```

4. **Expected Output:**
```
Hello, Java!
```

## Understanding the Code

- `public class HelloWorld` - Defines a public class named HelloWorld
- `public static void main(String[] args)` - The main method, entry point of any Java program
- `System.out.println()` - Prints text to the console followed by a newline

## Java Basics

| Concept | Description |
|---------|-------------|
| **Class** | A blueprint for creating objects |
| **Method** | A function defined inside a class |
| **main()** | The entry point where Java execution starts |
| **static** | Means the method belongs to the class, not instances |
| **void** | Indicates the method doesn't return any value |
